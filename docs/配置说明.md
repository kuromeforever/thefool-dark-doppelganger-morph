# 配置说明

最后更新：2026-08-29

本附属 `0.1.2` 不新增 Forge 配置文件。所有行为是经审计冻结的兼容合同，避免客户端或服务端参数不一致和第二套状态。

| 参数 | 固定值 |
| --- | --- |
| 来源版本 | Dark Doppelganger `9.8.2-1.20.1` |
| AOM | `[0.3.1,0.4.0)` |
| BetterMorph | `[0.0.54,0.0.55)` |
| 五主动共享冷却 | 60 tick（3 秒） |
| 单动作最大视觉时长 | 60 tick |
| 镜刃第二式概率 | 40%，且与第一式不同 |
| 镜刃伤害 | 第一式 12，第二式 8 |
| 生命汲取 | 半径 8、最多 8 目标、每目标 4 伤害、总治疗最多 16 |

玩家仍可通过 Minecraft 语言设置选择是否使用简体中文。来源 Iron 法术配置会继续影响来源法术自身允许公开控制的行为，但不会替换 AOM 的 60 tick 变身技能冷却。

升级任一精确依赖版本前，必须先更新来源 SHA-256、方法描述符、literal 次数、动画键与自动合同；不要通过放宽 Mixin `require`、扩大版本范围或删除 thin Jar门禁来绕过漂移。
